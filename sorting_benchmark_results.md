# Результаты тестирования сортировки

## Тестовая среда
- База данных: PostgreSQL
- ORM: Spring Data JPA + Hibernate
- Размер данных: 11,000 записей на таблицу

## Результаты


| Что сортируем | Как сортируем | Время (ms) |
|---------------|---------------|------------|
| Функции по имени | от А до Я | 48 |
| Функции по имени | от Я до А | 41 |
| Функции по ID | по возрастанию | 47 |
| Функции по ID | по убыванию | 39 |
| Точки по X | по возрастанию | 31 |
| Точки по X | по убыванию | 35 |
| Точки по Y | по возрастанию | 29 |
| Точки по Y | по убыванию | 39 |


**Примечание:** Время указано в миллисекундах (среднее по 20 запускам)

### Что значит сортировка:
- **от А до Я** - алфавитный порядок (func0, func1, func10...)
- **от Я до А** - обратный алфавитный порядок
- **по возрастанию** - от меньшего к большему (1, 2, 3...)
- **по убыванию** - от большего к меньшему (999, 998, 997...)
