# ⚡ Быстрый старт LAB2

## 🎯 Минимальные шаги для запуска

### 1. База данных (PostgreSQL)
```sql
CREATE DATABASE lab2_db;
CREATE USER lab2_user WITH PASSWORD 'lab2_pass';
GRANT ALL PRIVILEGES ON DATABASE lab2_db TO lab2_user;
```

### 2. Backend (Spring Boot)
```bash
# В корне проекта
mvn clean install -DskipTests
mvn spring-boot:run
```
✅ Backend запущен на **http://localhost:8080**

### 3. Frontend (React + Vite)
```bash
# В новом терминале
cd src/main/webapp
npm install
npm run dev
```
✅ Frontend запущен на **http://localhost:3000**

## 🚀 Использование

1. Откройте **http://localhost:3000**
2. Нажмите "Зарегистрироваться"
3. Создайте аккаунт
4. Войдите в систему
5. Создавайте функции! 🎉

#### 2️⃣ Создание функций из MathFunction
- ✅ Выбор функции из выпадающего списка
- ✅ Локализованные названия функций (русский язык)
- ✅ Упорядочение по алфавиту
- ✅ Map для соответствия названий и функций:
  - Квадратичная функция → SqrFunction
  - Тождественная функция → IdentityFunction  
  - Единичная функция → UnitFunction
  - Нулевая функция → ZeroFunction
  - Константная функция → ConstantFunction
- ✅ Ввод интервала и количества точек
- ✅ Использование фабрики

#### 3️⃣ Обработка исключений
- ✅ Модальные окна с ошибками (НЕ консоль!)
- ✅ Блокировка работы до закрытия окна
- ✅ Читаемая информация об ошибке
- ✅ Разная обработка для разных типов:
  - Отрицательное число → "Количество точек должно быть минимум 2"
  - Текст в поле → "Некорректные числа в строке N"
  - Пустые поля → "Заполните все значения"
  - Неупорядоченные X → "Значения X должны быть строго возрастающими"
- ✅ Интерфейс не ломается при ошибках
